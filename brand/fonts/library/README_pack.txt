Copyright-free fonts for video - Telugu + English
================================================

All fonts in this pack are from Google Fonts and are licensed under the
SIL Open Font License (OFL) version 1.1. A copy of the OFL is in every
font folder (OFL.txt).

What that means for your videos:
- Yes, you can use them in videos, including monetized YouTube /
  Instagram videos, thumbnails, titles and subtitles.
- Yes, you can install them on your computer / phone and use them in
  Premiere, DaVinci Resolve, CapCut, Canva, etc.
- You do NOT have to pay, and you do NOT have to credit the designer,
  though crediting is welcome.
- You must NOT sell the font files on their own, or claim you made them.
  (Embedding them in a video is fine - that is normal use, not selling
  the font.)

Source: https://github.com/google/fonts - downloaded 2026-10-27.
All 33 .ttf files were checked: valid TTF headers, and Telugu fonts
were checked to contain Telugu Unicode glyphs (U+0C00-U+0C7F).

HOW TO INSTALL
- Windows: right-click a .ttf > Install
- Mac: double-click a .ttf > Install Font
- Android / iOS video apps: import the .ttf from Files, or install
  via your editor's font import if it supports custom fonts.
  CapCut / VN / Alight Motion accept .ttf imports.

TELUGU - 15 families, 17 files - best for:
- Noto Sans Telugu - clean, safest default for body text / subtitles
- Noto Serif Telugu - serif, formal / story-style titles
- Mandali - clean news-style, very readable at small sizes
- Mallanna - round, crisp, good at small sizes
- Ramabhadra - bold-looking, good for headlines
- Hind Guntur (Regular / Medium / Bold) - modern, has real Bold
- Baloo Tammudu 2 - friendly, rounded, good for fun titles
- Suravaram - brush / handwriting style, for headings only
- Lakki Reddy - handwritten style, for headings only
- Gurajada - calligraphy-style, for headings only
- Dhurjati - square with round corners, for large headlines
- Tenali Ramakrishna, Timmana, Peddana, Ramaraja - classic Telugu text faces

ENGLISH - 8 families, 16 files - best for:
- Bebas Neue - tall condensed titles / hooks
- Oswald - condensed titles, variable weight
- Montserrat - modern titles and body, variable weight
- Poppins (Regular / Medium / SemiBold / Bold / ExtraBold) - clean modern, best all-rounder
- Inter - subtitles / body, very readable
- Lato (Regular / Bold / Italic / Black) - friendly body text
- Nunito - rounded, friendly, variable weight
- Raleway - elegant, variable weight

VARIABLE FONTS NOTE
Files with [wght] in the name (e.g. Montserrat[wght].ttf,
Oswald[wght].ttf, NotoSansTelugu[wdth,wght].ttf) are variable fonts:
one file holds many weights. Newer editors let you pick the weight.
If your editor only shows one weight for a variable font, use the
static families instead - Poppins or Lato for English, Hind Guntur
for Telugu (it has separate Regular / Medium / Bold files).

If a Telugu font shows boxes / broken conjuncts in an editor, switch
to Noto Sans Telugu or Mandali first - they have the widest Telugu
conjunct coverage in this pack. Test Telugu text in your editor
before a final export.
