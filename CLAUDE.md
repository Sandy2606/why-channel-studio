# Why? Channel Studio: instructions for Claude

1. At the start of every video session, run `bash setup.sh` (it links the pipeline, fonts, sounds and music into /home/claude/...).
2. Follow `playbook/why-channel-video-SKILL.md` (the master playbook: precedence, rule index and workflow). Also load `playbook/brand.md`, `playbook/platform_rules.md`, the role guides in `playbook/roles/` for the stage you are working on, the series plan in `plans/` and the video's production brief. Never load `playbook/history.md` as instructions; it is a historical record only. Where a saved account skill disagrees with these files, these files win.
3. For each video, create `videos/<YYYY-MM-DD>_<slug>/` and keep the production brief, script, scene sheet, asset register, cues, phrase anchors, take lists, QC report, post copy and thumbnails there. Templates are in `playbook/templates/`.
4. Sounds: use only the real recordings in `sfx/` (`sfx/catalog.json` gives each one's role and hit point). Ask the user for topic-specific extras in the visuals list; they upload them to `sfx/` (→ SD-04).
5. After every delivery, put the score, defects and lessons in `playbook/history.md` (EVIDENCE or TEST). Change a rule only when the user approves it: replace the old rule in its owner file, move the old text to `history.md` as SUPERSEDED, and update references (→ WF-05). Then commit and push to `main`.
6. Animation styles: `pipeline/styles/README.md` lists nine ready styles (Isometric, Paper-Cut, 3D Data Chart, Synthwave, 3D Explainer, Maths Diagram, Cartoon Explainer, Domino Reveal, Glow Atom). Consider them whenever you write a scene sheet, and use whichever fits the explanation.
7. Order of work: follow WF-01 in the master playbook. Scripts go through versions until the user approves the final script. Every scene sheet names the animation style for every line or chapter, and rendering waits until the user has agreed those styles.
8. Remotion effects: `pipeline/remotion_effects/README.md` lists 30 more clip effects (silent MP4s for the Python editors), in English and Telugu, for 9:16 and 16:9. Offer them in scene sheets alongside the nine Python styles. Their factual fields need sources unless they are shown as DEMO. Keep the two collections separate.
